# DispoBuddy — Premium Corporate Website Redesign Concept

An interactive, 10-page redesign concept and design presentation for **DispoBuddy.com**.

> **Disclaimer:** This is an independent redesign concept and interactive demo proposal. It is **not** the official live website and does **not** transmit form submissions, contact messages, or user data to any live backend.

## Included Pages (10/10)

1. `index.html` — Redesigned Homepage (all 12 sections)
2. `submit-deal.html` — Interactive 5-step Deal Submission Wizard (all 43 fields, validation, conditional blocks, local auto-save, demo property lookup, review step)
3. `what-we-look-for.html` — Deal Criteria & Requirements
4. `process.html` — 6-Step Disposition Process Breakdown
5. `proof.html` — Closed Deal Structures & Partner Proof
6. `join.html` — Partner Network Onboarding Application (local demo)
7. `contact.html` — Contact Page & Inquiry Form (local demo)
8. `buyers-map.html` — Interactive Leaflet Active Buyers Map (15-state demo visualization)
9. `terms.html` — Terms of Service
10. `privacy.html` — Privacy Policy

## How to Run Locally

From `G:\مواقع مبرمجة\dispobuddy`, choose any of the following options:

### Option 1: Included Node Preview Server (Recommended)
```bash
node server.js
```
Then open: **http://127.0.0.1:4173**

### Option 2: Python HTTP Server
```bash
python -m http.server 4173
```
Then open: **http://127.0.0.1:4173**

### Option 3: npx serve
```bash
npx serve . -l 4173
```
